# CAER — CS2 사건 맥락 재구성 PoC

의심스러운 킬의 이전 행동을 검색하고 AI 설명과 실제 근거 프레임을 제공하는 검토 보조 시스템입니다. 최종 판단은 사람이 합니다.

이 저장소는 이미 구현된 코드를 기능 의존 순서에 따라 정리·등록하고 있습니다. 현재는 프로젝트 기본 구성 단계이며, 뒤이은 모듈이 등록되면 전체 실행 안내와 검증 범위를 README에 통합합니다.

등록 순서: 기본 구성 → 원본 수집·검증 → 사건 선정 → v7 맥락 검색 → 영상·프레임 생성 → 전체 파이프라인 → AI 분석·재검토 → 시연 자료·평가 → UI·CLI → 최종 실행 안내.

가설은 이전 맥락 제공이 치팅 오탐을 줄이는 데 도움이 된다는 것입니다. 현재 PoC는 검색·설명·근거 확인 흐름을 구현하며 실제 치팅 오탐률 감소는 아직 검증하지 않았습니다.
